# Keyfe Keder Radyo — Android

Native Android radio player for Keyfe Keder Radyo.

## Stack
- Kotlin
- Android SDK 36
- Media3 / ExoPlayer
- MediaSession background playback
- OkHttp

## MVP
- Radio station list
- Search
- Favorites
- Native audio playback
- Background playback
- HLS support
- Optional relay fallback

The Android application is maintained in this repository independently from the web application.
